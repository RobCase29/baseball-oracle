# Hashtag Basketball Source Scope

## Recorded owner direction

On 2026-07-24, the project owner asked Hobby Oracle to use the resources
already pulled into the Checklist project to build a higher-signal basketball
player ranking. The referenced Checklist system already contained an
attributed, normalized Hashtag Basketball five-season dynasty snapshot used by
its production basketball release research.

This file records the owner's direction to reuse that existing normalized
snapshot inside Hobby Oracle. It is **not** a claim that Hashtag Basketball
granted permission, endorsed the product, or licensed its data.

## Provisional public-use boundary

Until provider permission is separately attested, the basketball adapter must:

- remain labeled as a provisional source scope;
- publish only the normalized fields needed for an attributed derived
  comparison;
- retain the provider name, source URL, source update date, and retrieval date;
- avoid publishing or reselling the raw page response;
- avoid model training or fitted optimization on the provider rankings;
- avoid expanding retrieval beyond the existing provider page and schema; and
- fail closed for a provider, source URL, schema, or semantic change.

The resulting Build Score is a deterministic research heuristic. It does not
represent Hashtag Basketball's view of sports cards, expected appreciation, or
investment advice.

## Review trigger

Provider permission should be recorded before removing the provisional label.
The scope must also be reviewed if the public fields, commercial use, access
method, source page, or scoring semantics materially change.
